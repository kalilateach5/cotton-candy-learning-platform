# Texas Grade 8 Mathematics TEKS

## 8.2 Number and Operations

### 8.2A
Extend previous knowledge of sets and subsets using a visual representation to describe relationships between sets of real numbers.

### 8.2B
Approximate the value of an irrational number.

### 8.2C
Convert between standard decimal notation and scientific notation.

### 8.2D
Order a set of real numbers arising from mathematical and real-world contexts.

## 8.7 Expressions

### 8.7A
Generalize properties of operations and apply them to simplify expressions.

### 8.7C
Use properties of integer exponents and scientific notation to solve problems.
