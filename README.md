# 🍭 Cotton Candy Learning Platform

An interactive middle school math review platform designed to increase engagement, provide meaningful student feedback, and give teachers actionable data.

## Current Features

✅ Cotton Candy themed student interface

✅ Branching review questions

✅ Hint-based learning

✅ Progress tracking

✅ Attempt tracking

✅ Time-on-task tracking

✅ Teacher analytics dashboard

✅ Canvas-compatible submission workflow
